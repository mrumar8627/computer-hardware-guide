# Monitor

## Purpose

A monitor displays visual output from the computer.

## Common Problems

- No display
- Flickering
- Incorrect resolution
- No signal
- Poor image quality

## Basic Troubleshooting

1. Check the power cable.
2. Check the display cable.
3. Check the monitor input source.
4. Check whether the computer is running.
5. Test another cable if available.
6. Test another monitor if available.
7. Check Windows display settings.

## Lesson Learned

Display problems should be isolated by checking power, cables, monitor input, computer output, and display settings.
