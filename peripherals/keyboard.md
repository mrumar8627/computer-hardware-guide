# Keyboard

## Purpose

A keyboard is an input device used to enter text and commands.

## Common Problems

- Keys do not work
- Keyboard is not detected
- USB connection problem
- Wireless connection problem

## Basic Troubleshooting

1. Check the connection.
2. Try another USB port.
3. Restart the computer.
4. Test the keyboard on another computer.
5. For wireless keyboards, check the batteries.
6. Check whether Windows detects the keyboard.

## Lesson Learned

Testing the keyboard on another computer can help determine whether the problem is with the keyboard or the computer.
