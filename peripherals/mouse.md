# Mouse

## Purpose

A mouse is an input device used to control the pointer and interact with applications.

## Common Problems

- Pointer does not move
- Mouse is not detected
- USB connection problem
- Wireless connection problem
- Buttons do not work

## Basic Troubleshooting

1. Check the connection.
2. Try another USB port.
3. Restart the computer.
4. Clean the sensor if necessary.
5. Check wireless batteries.
6. Test the mouse on another computer.

## Lesson Learned

Basic connection and device testing can help identify common mouse problems.
