# Storage

## What Is Computer Storage?

Storage devices are used to permanently store the operating system, applications, and user data.

Common storage technologies include:

- HDD
- SSD

## HDD

A Hard Disk Drive uses mechanical components to store data.

## SSD

A Solid State Drive uses flash memory and has no moving mechanical parts.

## Common Storage Problems

- Low disk space
- Slow system performance
- Drive not detected
- File access problems
- Storage device failure

## Basic Troubleshooting

1. Check available disk space.
2. Check whether the drive appears in Windows.
3. Check Disk Management when required.
4. Check cables for SATA drives.
5. Check drive health using appropriate tools.
6. Back up important data before performing risky troubleshooting.

## Lesson Learned

Storage is important for both system performance and data availability. Important data should be backed up regularly.
