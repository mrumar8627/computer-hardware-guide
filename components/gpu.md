# GPU

## What Is a GPU?

GPU stands for Graphics Processing Unit.

It processes and renders graphics and visual output.

## Common Uses

- Display output
- Video processing
- Gaming
- 3D applications
- Graphics-intensive software

## Common GPU Problems

- No display
- Display artifacts
- Driver problems
- System crashes during graphics-intensive tasks
- GPU overheating

## Basic Troubleshooting

1. Check the display cable.
2. Check the monitor input.
3. Check whether the GPU is properly installed.
4. Check GPU drivers.
5. Check GPU temperature.
6. Test another display cable or monitor when available.

## Lesson Learned

GPU problems can be caused by hardware, drivers, cables, or display configuration.
