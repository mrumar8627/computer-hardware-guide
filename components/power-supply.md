# Power Supply

## What Is a Power Supply?

The Power Supply Unit (PSU) provides electrical power to the computer's internal components.

## Main Functions

- Supplies power to the motherboard
- Supplies power to storage devices
- Supplies power to the CPU
- Supplies power to other hardware components

## Common PSU Problems

- Computer does not turn on
- Computer shuts down unexpectedly
- System restarts
- No power to components
- Burning smell or unusual noise

## Basic Troubleshooting

1. Check the power cable.
2. Check the wall socket.
3. Check the PSU power switch if available.
4. Check external power connections.
5. Check whether the computer shows any power indicators.
6. If PSU failure is suspected, seek appropriate technical assistance.

## Safety

Do not open a power supply unit unless properly trained and qualified. Power supplies can contain dangerous electrical components.

## Lesson Learned

A stable power supply is essential for reliable computer operation.
