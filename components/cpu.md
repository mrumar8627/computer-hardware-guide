# CPU

## What Is a CPU?

CPU stands for Central Processing Unit.

It is one of the main components of a computer and processes instructions required by the operating system and applications.

## Main Functions

- Processes instructions
- Performs calculations
- Executes program operations
- Coordinates processing tasks

## Important CPU Specifications

- Number of cores
- Number of threads
- Clock speed
- CPU generation
- Socket type
- Power requirements

## Common CPU Problems

- Computer does not boot
- System becomes slow
- High CPU usage
- Overheating
- Unexpected shutdowns

## Basic Troubleshooting

1. Check CPU temperature.
2. Check CPU usage in Task Manager.
3. Make sure the cooling system is working.
4. Check for dust around the cooling system.
5. Make sure the CPU cooler is properly installed.
6. Check whether the problem continues after restarting.

## Lesson Learned

The CPU is a critical component that directly affects system processing and performance.
