# RAM

## What Is RAM?

RAM stands for Random Access Memory.

It temporarily stores data and instructions that the computer is currently using.

## Main Functions

- Stores active data
- Helps applications run
- Supports multitasking
- Provides fast temporary access to data

## Common RAM Problems

- Computer does not boot
- System freezes
- Applications crash
- Slow performance
- Unexpected restarts

## Basic Troubleshooting

1. Check the amount of installed RAM.
2. Check memory usage in Task Manager.
3. Restart the computer.
4. If required, check whether the RAM modules are properly installed.
5. Test the system after reseating or replacing RAM when appropriate.

## Lesson Learned

Insufficient or faulty RAM can affect system stability and performance.
