# Motherboard

## What Is a Motherboard?

The motherboard is the main circuit board of a computer.

It connects and allows communication between major hardware components.

## Components Connected to the Motherboard

- CPU
- RAM
- Storage devices
- GPU
- Power supply
- USB devices
- Expansion cards

## Common Motherboard Problems

- Computer does not boot
- Hardware is not detected
- USB ports do not work
- System randomly shuts down
- No display

## Basic Troubleshooting

1. Check power connections.
2. Check whether RAM is properly installed.
3. Check connected hardware.
4. Check USB devices and ports.
5. Check for visible physical damage.
6. Check whether the motherboard shows diagnostic indicators, if available.

## Lesson Learned

The motherboard provides the main connection between many computer components.
