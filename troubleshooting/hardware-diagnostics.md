# Basic Hardware Diagnostics

## Purpose

This guide documents a basic process for identifying common computer hardware problems.

## Diagnostic Process

### 1. Identify the Problem

Understand what the user is experiencing.

Examples:

- Computer does not start
- No display
- Computer is slow
- Device is not detected
- System shuts down unexpectedly

### 2. Check Basic Connections

Check:

- Power cables
- Display cables
- USB connections
- Network cables
- Peripheral connections

### 3. Check Windows

Use Windows tools to check:

- Task Manager
- Device Manager
- System Information
- Windows Settings

### 4. Test the Hardware

When possible:

- Test another cable
- Test another peripheral
- Test another monitor
- Test the device on another computer

### 5. Identify the Possible Cause

Compare the results of the tests and identify the most likely cause.

### 6. Apply a Basic Solution

Perform an appropriate troubleshooting step.

### 7. Test Again

Confirm whether the problem has been resolved.

### 8. Document the Result

Record:

- Problem
- Checks performed
- Cause identified
- Solution
- Final result

## Safety

Do not perform hardware repairs or electrical work without appropriate knowledge and safety procedures.

## Lesson Learned

Good hardware troubleshooting is a systematic process of checking, testing, isolating, and documenting problems.
